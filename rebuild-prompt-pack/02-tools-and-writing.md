# 工具平台与写作提示词

共同前提：[公共契约](00-shared-contract.md) 与 A01–A03 的批准产物。

## A04 — 内置工具注册契约

**输入**：桌面骨架、架构规格、本阶段实施授权。

**可直接发送的提示词：**

实现受信任内置工具的中央注册机制。工具描述包含稳定标识、展示名称、图标、排序、视图入口、契约版本，以及声明的平台能力和可选后台任务元数据。标识需有一致可验证规则；拒绝重复标识、空名称、不支持的版本、未知能力和重复任务标识。查询列表不应允许调用者修改注册表内部状态。

面板通过注册表生成导航与视图；新增一个工具不应修改面板核心分支。优先提供设置/历史/AI、Planner 数据与图片、调度状态、通知操作等分组平台能力，不暴露通用执行器。工具后台元数据不包含从 renderer 传入的函数或代码。

将“声明能力”与“授权执行”分开：registry 校验不能成为可信调用身份的替代品。共享 renderer 内的工具不是隔离进程，不支持未经审查的远程插件。主进程仍独立验证来源、参数与资源归属。

**验收**：注册错误有稳定类别；排序稳定；通过注册新增最小示例工具无需改面板；不暴露 Node 或任意 IPC；若保存上次工具选择，对已移除工具能回退。生命周期与健康检查仅在明确需要时加入，不制造空洞框架。

## A05 — AI 服务、设置和安全配置

**输入**：A03/A04、获批的 AI 数据策略；默认使用模拟提供方。

**可直接发送的提示词：**

在主进程实现可替换的对话 AI 适配层，统一请求、文本结果及错误，不将供应商 SDK 或原始响应泄露给 UI。设置支持获批服务的端点、模型/部署、可选 API 版本、温度、请求超时等参数；不硬编码公司地址或模型名称。

密钥通过专用保存操作进入主进程，受操作系统安全存储保护；设置读取仅返回“已配置/未配置”和非敏感参数。支持替换与清除。不能把密钥返回 renderer、写入普通数据库明文或日志。安全存储不可用时按公共契约处理。

真实请求前说明出站内容与目标，使用 HTTPS 和接收方批准的端点策略。区分未配置、参数非法、认证失败、限流、网络失败、超时、空响应、格式不匹配。设计有限且可审计的重试策略：不对认证/参数错误盲重试，不把已产生费用的请求假定为无副作用操作。

本地测试使用确定性的模拟服务，覆盖正常、慢响应、错误及畸形返回。离线情况下应用的本地功能仍可用，AI 功能显示明确原因。设置页含保存/加载/错误状态，不能要求用户在聊天中发密钥。

**验收**：UI 永远读不到保存后的原密钥；日志和结果不回显鉴权头；超时不会卡住界面；服务错误稳定可见；模拟调用不访问网络。真实连通性测试须单独授权并明确记录。

## A06 — 中英翻译与润色及历史

**输入**：A04/A05、已批准 UI、历史仓储实施授权。

**可直接发送的提示词：**

实现写作工具：输入文本，选择目标语言为英语或中文，执行翻译并自然润色，尽量保持原意、名称、数字和结构，不虚构事实；结果区可编辑、复制。独立编写提示策略，不使用任何旧仓库提示模板。默认只返回处理后的内容，不附多余解释。

行为要求：空白输入不提交；运行中显示状态并防重复；清空输入和结果时解除历史选择；单独重置结果不必清空输入；失败不覆盖为成功历史。清理模型额外包裹格式时不能破坏合法代码或正文字符。

成功历史保存工具身份、输入、输出、目标语言、使用的模型和时间。新请求创建新记录；选中历史后恢复内容和目标语言，再次执行更新该选中记录；用户手动编辑结果可保存回选中记录。提供历史搜索、选中、单条删除、清空本工具历史，删除/清空有合适确认，不影响其他工具记录。

数据库操作失败与 AI 请求失败分开呈现；若生成成功但保存失败，保留可复制结果并提示未保存。复制失败可通过受控能力降级，不能因此授予任意系统访问。

**验收**：双向转换、重复点击保护、历史新建/更新/检索/删除、重启持久化、模型失败和存储失败均有行为测试。可在无真实 AI 凭据下完整演示，不声称模拟结果代表真实翻译质量。
